# 0trm.github.io

User site for [0trm.dev](https://0trm.dev). GitHub Pages publishes the `gh-pages` branch, which is written by a deploy workflow in the private repo `0trm-corp/0trm.dev`. Don't edit `gh-pages` by hand: the next deploy overwrites it.

Because this is the user site and holds the custom domain, every `0trm` project site is served at `0trm.dev/<repo>/` (for example `0trm.dev/gallop/`).
